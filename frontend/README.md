# WasteLess frontend

Create React App project. See the [root README](../README.md) for what it does and how it is built.

```bash
npm install
npm start        # http://localhost:8124 (port set in .env.development), demo mode
npm run build    # static site in build/
```

Live mode needs the variables listed in `.env.example` (put them in `.env.local`).
